!Finance Manager!

Консольна програма на Python для зручного обліку особистих фінансів. Вона допомагає контролювати грошові потоки, фіксувати щоденні доходи та витрати, а також аналізувати поточний фінансовий стан.

*Основні можливості:*

Додавання доходів і витрат із вказуванням суми, категорії та опису

Перегляд повного списку всіх транзакцій у вигляді таблиці

Розрахунок загальної суми доходів, витрат та поточного балансу

Фільтрація записів за конкретною категорією

Видалення транзакцій за їхнім ідентифікатором (ID)

*Структура файлів:*

main.py — головний файл програми, який містить меню користувача та обробку вибору дій

transactions.py — модуль для збереження, виведення та видалення транзакцій

statistics.py — модуль для обчислення фінансових показників та фільтрації

README.md — опис та документація проєкту

.gitignore — файл зі списком ресурсів, які ігноруються системою Git

Інструкція запуску:

Відкрийте термінал у папці з проєктом.

Запустіть програму за допомогою команди:
python3 main.py

*Приклади використання:*

Додавання витрати:

У головному меню оберіть пункт 2 (Додати витрату).

Введіть суму: 155

Введіть категорію: food

Введіть опис: huba

Перегляд транзакцій:

У головному меню оберіть пункт 3 (Переглянути всі транзакції).

Програма виведе таблицю з усіма доданими записами, їхніми ID, типами, сумами та категоріями.

Перевірка балансу:

Оберіть пункт 6 (Показати поточний баланс), щоб побачити різницю між усіма доходами та витратами.
